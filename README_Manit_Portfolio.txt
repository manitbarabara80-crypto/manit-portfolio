MANIT BARABARA TEBLIGU — PORTFOLIO WEBSITE
==========================================

Files
-----
index.html  Complete responsive portfolio website in one file.

Open locally
------------
1. Extract the ZIP file to a folder.
2. Double-click index.html to open it in Chrome, Firefox, or Edge.
3. Click "Customize" to update your name/title, story, accent colors, background motion,
   profile photo, email/phone, social URLs, skills, and add a project.
4. Settings are saved in the same browser on the same device using localStorage.
   Use Export settings to keep a JSON backup. A browser's local changes do not automatically
   change the file or the online website.

Social links
------------
In Customize, enter one URL per line as platform=https://... . Supported keys:
whatsapp, facebook, telegram, tiktok, youtube, linkedin, github, instagram, x.
Example:
linkedin=https://www.linkedin.com/in/your-profile
github=https://github.com/your-username
whatsapp=https://wa.me/2519XXXXXXXX

Contact form
------------
The form prepares an email in the visitor's email app (mailto). It does not deliver messages
through a server and does not store submissions. For a hosted server-side form, connect a
form provider or backend and configure it separately.

Publish free (example: GitHub Pages)
------------------------------------
1. Create/sign in to a GitHub account and create a public repository named
   your-username.github.io (replace with your actual GitHub username).
2. Upload index.html to the repository's root.
3. Open repository Settings > Pages and choose deploy from the main branch/root if asked.
4. Wait for the deployment and open https://your-username.github.io .
   Replace the example username with your real username.
Alternative: use Netlify Drop by uploading the folder containing index.html at
https://app.netlify.com/drop. Follow the hosting provider's current prompts.
You must have an account and internet access to publish. Never share your password with anyone.
